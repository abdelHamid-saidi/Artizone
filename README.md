# Artizone

**Artizone** est une plateforme de mise en relation entre particuliers et artisans locaux, composée de trois parties principales :

- **Application mobile** pour les particuliers (React Native)
- **Interface web** pour les administrateurs (React.js)
- **API backend** sécurisée (Laravel ou Node.js + Express)

## 🔧 Structure du projet

```

artizone/
├── mobile/ # Application React Native
├── web/ # Interface React.js (Admin)
├── backend/ # API (Laravel ou Node.js)
├── database/ # Dump SQL et migrations
├── docs/ # Cahier des charges, doc API

```
