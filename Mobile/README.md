# Artizone Web Admin

Interface web en React.js pour gérer les demandes des particuliers.

## 🖥️ Fonctionnalités

- Authentification administrateur
- Visualisation et validation des commandes
- Tableau de bord avec statistiques
- Suivi des utilisateurs et signalements
- Contact manuel avec les artisans

 ## 🚀 Lancer le projet web

```bash
cd web
npm install
npm start

 ```
